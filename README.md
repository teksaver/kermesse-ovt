# Kermesse

Application web CodeIgniter 4 pour organiser les inscriptions de benevoles d'une kermesse.

## Developpement local

L'environnement local conteneurise compatible OrbStack est documente dans [`docs/local-orbstack.md`](docs/local-orbstack.md).

Demarrage rapide :

```bash
docker compose up --build
```

Application locale :

```text
http://localhost:8080/
```
