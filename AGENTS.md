# Instructions Projet

- Utiliser `uv run python` pour toutes les commandes Python du projet.
- Ne pas appeler `python`, `python3` ou les scripts Python BMad directement.
- Exemple correct : `uv run python _bmad/scripts/resolve_customization.py --skill .agents/skills/bmad-dev-story --key workflow`.
- **Règle absolue** : Avant de planifier une tâche ou d'écrire du code, lire impérativement le fichier `project-context.md` situé à la racine du projet pour assimiler les règles architecturales de Kermesse.
